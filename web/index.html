WebCLAP EQ

Free EQ plugins that run in the browser, in DAWs such as openDAW.

Plugins

Console EQ

A channel EQ in the style of a British mixing console: high-pass and low-pass filters, low and high bands that switch between shelf and bell, and two mid bands with adjustable width (Q).

Download Try the controls

"Try the controls" opens the plugin's controls in your browser without sound, so you can see how the knobs and the curve work.

Using a plugin in openDAW

  1. Download the plugin file. Keep it as it is, a .wclap.tar.gz file; there's no need to unpack it.
  2. In openDAW, import the file as a WebCLAP plugin.
  3. Add the plugin as an effect on an audio track and open its window.

If the plugin window is blocked

openDAW shows plugin windows from a separate address. If a plugin window shows a "blocked page" message instead of the plugin, your browser or network is blocking that address. Your browser needs access to both of these sites (on a school or work computer, ask whoever manages it to allow them):

  • opendaw.studio
  • opendaw-plugins.studio
