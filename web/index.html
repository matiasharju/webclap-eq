Free audio plugins that run in browser-based DAWs such as openDAW

Console EQ

A channel EQ in the style of British mixing consoles: high-pass and low-pass filters (HPF and LPF), low and high bands that switch between shelf and bell, and two mid bands with adjustable width (Q).

Using a plugin in openDAW

  1. Download the file to your computer (it usually goes to your Downloads folder). Keep it as it is, a .wclap.tar.gz file; there's no need to unpack it.
  2. Open openDAW and add a WebCLAP effect to an audio track (Tape).
  3. In the effect, choose Load Plugin → Import WebCLAP, and pick the .wclap.tar.gz file you downloaded.
  4. Click Open UI to open the plugin window, or choose Parameters to create automation and more.

If the plugin window (UI) is blocked

openDAW shows plugin windows from a separate address. If a plugin window shows a 'blocked page' message instead of the plugin, your browser or network is blocking that address. Your browser needs access to both of these sites (on a school or work computer, ask whoever manages it to allow them):

  • opendaw.studio
  • opendaw-plugins.studio
